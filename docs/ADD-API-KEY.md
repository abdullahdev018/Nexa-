# Add your API key

This is the only setup step that needs a real secret. It takes about a minute.

**You never send the key to Claude.** You paste it into one file on your own
machine, then say `ok` in the chat. Claude reads whether the key *works* — never
the key itself.

---

## The one line you edit

| | |
|---|---|
| **File** | `.env.local` |
| **Full path** | `/Users/apple/AndroidStudioProjects/ABDai/nexa-ai/.env.local` |
| **Line** | **20** |
| **Marked with** | `# 👇 PASTE YOUR OPENROUTER KEY ON THE NEXT LINE` |

That file is listed in `.gitignore`, so it is never committed and never leaves
your computer. It is the only file you should ever put a real key in.



## Step 1 — get a key

Pick one. OpenRouter is the default and reaches every model the app offers.

| Provider | Where | Key looks like |
|---|---|---|
| **OpenRouter** (default) | https://openrouter.ai/keys | `sk-or-v1-…` |
| Anthropic | https://console.anthropic.com/settings/keys | `sk-ant-…` |

Copy it the moment it is shown — both sites show a key once and never again.

## Step 2 — open the file

In Android Studio: `Cmd+Shift+O`, type `.env.local`, Enter.

Or from a terminal:

```bash
cd /Users/apple/AndroidStudioProjects/ABDai/nexa-ai
open -e .env.local
```

## Step 3 — paste on line 20

Scroll to the 👇 arrow. The line under it looks like this — **this block is a
picture of what you will see, not a place to type. Do not edit this file.**

```bash
# 👇 PASTE YOUR OPENROUTER KEY ON THE NEXT LINE, straight after the "=" sign
OPENROUTER_API_KEY=sk-or-v1-abc123yourrealkeyhere
```

Put your cursor right after the `=` and paste, so it becomes:

```bash
OPENROUTER_API_KEY=sk-or-v1-abc123yourrealkeyhere
```

Four rules — every failed key so far has broken one of them:

| | |
|---|---|
| ❌ no quotes | `OPENROUTER_API_KEY="sk-or-v1-…"` |
| ❌ no space after `=` | `OPENROUTER_API_KEY= sk-or-v1-…` |
| ❌ no angle brackets | `OPENROUTER_API_KEY=<sk-or-v1-…>` |
| ❌ never split across lines | the whole key stays on line 20 |

Save the file (`Cmd+S`).

### Using an Anthropic key instead?

Leave line 20 empty and use **OPTION B** further down the same file: delete the
`#` from the start of the two lines under the second 👇 arrow, paste your
`sk-ant-…` key, and save. That switches the app to the Anthropic adapter.

## Step 4 — tell Claude `ok`

Just type **`ok`** or **`key added`** in the chat. Claude then runs:

```bash
npm run verify:key
```

which checks the shape of the key and makes a real call to the provider to
confirm it is accepted, then restarts the dev server and sends a live chat
message through the website to prove it works end to end.

The output only ever shows the key's **length and last 4 characters** — for
example `73 characters, ending ...8f2a` — so nothing secret appears on screen.

You can run that command yourself at any time too.

---

## If it says "out of credit"

This means the key is **correct and installed** — the account behind it just has
no money in it. OpenRouter charges per message, and a new account starts at $0.

Add credit at **https://openrouter.ai/credits**. A few dollars lasts a long time
at these model sizes.

**Free models are not a workaround.** OpenRouter's `:free` models either queue
forever on a $0 balance or are restricted to approved apps — both were tested
here and neither returned a reply.

---

## If it says FAILED

| Message | What it means | Fix |
|---|---|---|
| `is empty` | Nothing was saved on line 20 | Paste after the `=`, then `Cmd+S` |
| `placeholder is still there` | `<...>` was left in place | Replace it including the `<` and `>` |
| `contains a space` | A space came along with the paste | Delete every space on line 20 |
| `must start with sk-or-v1-` | It is an Anthropic key, not OpenRouter | Use OPTION B in `.env.local` |
| `rejected the key (401/403)` | Real key, but revoked or wrong account | Create a fresh one |
| `no credit (402)` | Key is valid, wallet is empty | Add credit at the provider |

---

## Never do these

- **Never paste the key into this chat.** Anything typed in chat is stored in
  the conversation transcript. The whole point of line 20 is that Claude can
  confirm the key works without ever seeing it.
- **Never put it in `.env.example`** — that file *is* committed. It is a
  template and must only ever hold empty values.
- **Never prefix it with `NEXT_PUBLIC_`.** That would ship your key to every
  visitor's browser. The key is read only by `lib/ai/*`, which is server-only.
- **Never paste it into a component, a page, or any file under `app/`.**

## How the app reads it

```
.env.local  line 20
     ↓
process.env.OPENROUTER_API_KEY
     ↓
lib/ai/openrouter.ts        ← server-only, marked with `import 'server-only'`
     ↓
lib/ai/index.ts             ← picks the adapter from AI_PROVIDER
     ↓
app/api/chat/route.ts       ← the website's chat endpoint
```

`instrumentation.ts` checks the key at boot, so a missing one shows up in the
startup log as a clear line rather than as a broken chat later.
